Standalone Screen Capture

The browser no longer captures screenshots. Use the Windows ScreenCapture app to OCR TikTok LIVE Studio locally and send only text to your backend.

Local OCR + webhook

1. Configure the webhook

Set SCREEN_CAPTURE_WEBHOOK_TOKEN in your Render backend environment to a long random secret. Paste the same secret below; it is used only to build the desktop app's webhook URL.

Webhook URL for the ScreenCapture app

2. Configure ScreenCapture on Windows

  1. Extract ScreenCapture.zip and start live_ocr.py following its README.
  2. Select the TikTok LIVE Studio window and draw a small region around the chat messages and a separate region for gift/follow/join alerts if needed.
  3. Open Outputs... and enable the webhook sink.
  4. Paste the generated webhook URL. Enable the JSONL file sink as a backup.
  5. Set the capture interval to about 1 second and turn on New lines only.
  6. Click Test, then Start. Check this dashboard's Live activity page and keep Avatar Studio open.

ScreenCapture extracts text on your PC. The backend sends that text to the Groq text model (openai/gpt-oss-20b) to select relevant viewer interactions. No image is sent to Groq or OpenAI for vision analysis.

3. Keep normal viewer interactions enabled

Direct TikTok chat, joins, follows, and gifts continue through the existing event listener. Screen OCR is an additional input only; both inputs feed the same priority queue so the avatar can speak without overlapping lines.

For security, never use your admin token as the screen-capture token. Keep SCREEN_CAPTURE_WEBHOOK_TOKEN secret.

Backend: https://tik-backend.onrender.com · OCR runs locally on your Windows PC.
